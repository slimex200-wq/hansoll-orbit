# Project Knowledge

This folder stores small, reviewable project knowledge for the private Talbots workbench.

These files are not raw business documents. They are operating rules, handoff notes, and layout specifications that help a fresh Codex chat avoid generic behavior.

Tracked here:

- `current_session_handoff.md`: current Park Daeri session context for fresh chats.
- `new_chat_bootstrap_prompt.md`: copy-paste prompt when a new chat does not pick up the project context.
- `talbots_workflow_rules.md`: confirmed Talbots/MGF workflow rules.
- `workbook_layout_specs/`: small JSON layout checks for generated Excel files.

Good candidates for this folder:

- confirmed data source locations
- form/template conventions
- approval or review rules
- human-confirmation triggers
- output format preferences
- lessons learned from bad outputs that should not repeat

Do not commit private source documents, raw mail bodies, generated workbooks, or credentials.
